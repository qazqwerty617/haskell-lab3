# Лабораторна робота №3 (Haskell)

**Тема:** Обробка тексту підручника з програмування  
**Варіант:** 13  

---

## Завдання

1. Створити модель тексту з відповідними типами даних:
   - `Symbol` — окремий символ;
   - `Punctuation` — розділовий знак;
   - `Word` — послідовність символів (слово);
   - `Sentence` — послідовність слів і розділових знаків;
   - `Text` — послідовність речень.
2. Реалізувати розбір тексту (розбиття на речення, слова, розділові знаки) із заміною всіх табуляцій та послідовностей пробілів одним пробілом.
3. Відсортувати слова тексту за зменшенням кількості входжень заданого символу, а в разі рівності кількості входжень — за абеткою (з урахуванням українського алфавіту).

---

## Структура проєкту

- `TextSort.hs` — вихідний код програми на Haskell.
- `textbook.txt` — вхідний текст підручника з функціонального програмування.
- `.gitignore` — ігнорування скомпільованих файлів GHC та артефактів збірки.

---

## Компіляція та запуск

```bash
# Компіляція з оптимізацією
ghc -O2 TextSort.hs

# Запуск з текстовим файлом за замовчуванням (textbook.txt)
./TextSort

# Запуск з довільним текстовим файлом
./TextSort my_text.txt
```
